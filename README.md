# Alasha · Katon-Karagai — eco-resort website

Production website for **Alasha**, an eco-resort in Katon-Karagai (Altai mountains, East Kazakhstan). Guests see the rooms and the location and book a stay in one tap through WhatsApp.

🔗 **Live:** https://www.alashakaton.kz

## Features

- Three languages — Kazakh, Russian, English
- Eco-rooms for 2 and 5 guests with photos
- Location section with an embedded map
- Booking and contacts via WhatsApp
- Responsive design for phones and desktops
- Custom domain

## Tech

React 19 · Vite · JavaScript · CSS · deployed on Vercel

## Run locally

```bash
npm install
npm run dev
```
